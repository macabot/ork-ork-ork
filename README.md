# Ork ork ork

## Requirements

- [LilyPond](https://lilypond.org/)
- `fluidsynth`
- `fluid-soundfont-gm`
- `ffmpeg`

### Optional

- [Frescobaldi](https://www.frescobaldi.org/)
  - Requires: `qsynth -n`

## Build

Run

```shell
lilypond ork-ork-ork.ly
```

This creates:

- ork-ork-ork.midi
- ork-ork-ork.pdf
